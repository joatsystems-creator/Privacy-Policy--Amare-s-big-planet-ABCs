# Amare's Big Planet: ABCs — Privacy Policy

Static privacy policy page linked from the Google Play listing.

Plain HTML and CSS. No framework, no build step, no JavaScript, no cookies,
no analytics, no external fonts — the page loads nothing but its own two files.

    index.html    meta-refresh to the policy
    privacy.html  the policy
    style.css     styles
    vercel.json   security headers only (no build)

Deployed as a static site on Vercel. Editing `privacy.html` and pushing to
`main` redeploys. Update the "Last updated" date whenever the text changes.
